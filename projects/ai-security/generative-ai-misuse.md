# AI Security: Generative AI Misuse & Mitigation

[<- Back to Projects]({{ '/projects.html' | relative_url }})

## Project Overview
This project explores the security risks associated with Large Language Models (LLMs) and Generative AI. I investigated common attack vectors such as prompt injection, sensitive data disclosure, and model poisoning, while developing mitigation strategies to secure AI-driven applications.

### Key Focus Areas
*   **OWASP Top 10 for LLMs:** Deep dive into the most critical vulnerabilities in AI systems.
*   **Prompt Injection:** Demonstrating how malicious inputs can bypass safety filters and hijack model output.
*   **Data Privacy:** Analyzing the risk of LLMs leaking sensitive training data or user information.
*   **Mitigation Strategies:** Implementing robust system prompts and output validation to reduce agency and bound consumption.
