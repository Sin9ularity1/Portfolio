# 2nd Semester Project: Systems Hardening & Monitoring

[<- Back to Projects]({{ '/projects.html' | relative_url }})

## Project Overview
This project involved the deployment and securing of an on-premise server environment. I focused on centralized visibility and reducing the attack surface of the internal server infrastructure.

### What I Did (Systems)
*   **Server Deployment:** Managed Ubuntu Server instances for internal applications and infrastructure services.
*   **Wazuh SIEM:** Deployed a Wazuh manager and configured agents on all servers for real-time threat detection.
*   **Centralized Logging:** Consolidated system logs and security events into a single dashboard.
*   **File Integrity Monitoring:** Configured FIM to detect unauthorized changes to critical system files.
*   **Vulnerability Assessment:** Used Wazuh to perform automated vulnerability scans and identify missing security patches.
