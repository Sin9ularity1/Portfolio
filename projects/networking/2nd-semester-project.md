# 2nd Semester Project: Enterprise Network Infrastructure

[<- Back to Projects]({{ '/projects.html' | relative_url }})

## Project Overview
For my 2nd-semester project, I designed and implemented a secure network for a small-to-medium enterprise. The focus was on robust segmentation and perimeter security using professional-grade open-source tools.

### What I Did (Networking)
*   **Perimeter Security:** Configured an OPNsense firewall as the primary gateway.
*   **VLAN Segmentation:** Created isolated networks for Management, Employees, Servers, and Guests to prevent lateral movement.
*   **DMZ Implementation:** Established a De-Militarized Zone for public-facing services.
*   **VPN Access:** Configured a secure VPN gateway for remote administrative access.
*   **Traffic Filtering:** Implemented granular firewall rules to enforce the principle of least privilege.
